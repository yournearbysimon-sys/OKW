# cfx_gn_biker_grapeseed

-> gn_grapeseed_biker_entityset.lua

We've created 2 different layouts for the barn, so you can choose to change the layout using the entityset:

biker_a = simple & legal layout
gunrunning = reduction of arms traffic

Simply change the "true" or "false" value (obviously do not load both at the same time).
