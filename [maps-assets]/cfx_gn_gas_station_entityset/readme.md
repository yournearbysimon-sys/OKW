# Gas Station EntitySets

Different **EntitySets** (interior finishes) are available for the Gas Station interior.  
We provide the script **`gn_gas_station_entityset`** to help you easily manage and test the desired finish.

## How to use
1. Open the file **`gn_gas_station_entityset.lua`**.
2. Set the values to **`true`** or **`false`** according to your needs.
3. Save the file.
4. Restart the resource.

> 💡 You are not required to use this script — you can also add the configurations to your own script.

---

## Additional Information

**IPL name:**  `int_gn_gas_route68_milo` = cfx_gn_gas_route68 (road68 location) = 49.05748, 2795.029, 58.6707344
**MLO name:**  `int_gn_gas_station`

| EntitySet          |  Description          |
