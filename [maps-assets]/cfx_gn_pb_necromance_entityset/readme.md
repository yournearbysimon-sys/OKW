# Paleto Bay Necromance - Warehouse Interior EntitySets

Different **EntitySets** (interior finishes) are available for the warehouse.  
We provide the script **`cfx_gn_pb_necromance_entityset`** to help you easily manage and test the desired finish.

## How to use
1. Open the file **`gn_pb_necro_warehouse_entityset.lua`**.
2. Set the values to **`true`** or **`false`** according to your needs.
3. Save the file.
4. Restart the resource.

> 💡 You are not required to use this script — you can also add the configurations to your own script.

---

## Additional Information

**IPL name:**  `int_gn_necromance_wh_milo_`
**MLO name:**  `int_gn_necromance_wh`

### EntitySet List & Descriptions

| EntitySet              | Description                                                                                   |
|------------------------|-----------------------------------------------------------------------------------------------|
| `gn_necro_wh_empty`    | Empty warehouse (useful for creating your own setups in-game)                                 |
| `gn_necro_wh_meth`     | Meth lab setup                                                                                |
| `gn_necro_wh_weed`     | Weed base setup                                                                               |
| `gn_necro_wh_dry`      | Adds drying weed props *(requires `gn_necro_wh_weed` to be active)*                           |
| `gn_necro_wh_stage`    | Adds plantings in soil containers *(requires `gn_necro_wh_weed` to be active)*                |
| `gn_necro_wh_poaching` | Poaching setup                                                                                |
